# 📊 Data Science Salary Dashboard

## 📌 Project Overview

This project is an interactive **Data Science Salary Dashboard** developed in Microsoft Excel.

The purpose of the dashboard is to explore and compare salary information for data-related jobs using different combinations of **job title, country, and job type**.

The project helped me apply the Excel data analysis skills I developed during my training and turn a large dataset into an interactive and easy-to-understand dashboard.


### Dashboard File
My final dashboard is in [1_Salary_Dashboard.xlsx](1_Salary_Dashboard.xlsx).

## 🎯 Project Objective

The main objective of this project was to analyze salary data and create an interactive dashboard that allows users to explore salary information based on different criteria.

The dashboard allows users to:

- Select a **Job Title**
- Select a **Country**
- Select a **Job Type**
- View the corresponding **Median Salary**
- Compare salary levels across different data-related roles


## 📂 Dataset

The project uses a dataset containing more than **32,000 job records** related to data and technology careers.

The dataset contains information such as:

- Job Title
- Country
- Salary
- Job Type
- Job Location
- Company
- Job Skills
- Work-from-home information
- Education requirements
- Other job-related information

The dataset provides a basis for exploring salary patterns across different data-related careers and locations.

## 💡 Key Insights

The analysis shows that salary levels vary across job titles, countries, and job types.

The dashboard makes it possible to explore these differences interactively by changing the selected criteria.

For example, users can select a specific data-related role and country to view the corresponding median salary for the selected job type.

> **Note:** The results shown in the dashboard are based on the dataset used for this project and should be interpreted within the context of that dataset.
