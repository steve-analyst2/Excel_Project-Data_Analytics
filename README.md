# Project 3 — E-Commerce Sales Analysis

## Project Overview

This project demonstrates an end-to-end **e-commerce data analysis workflow using Microsoft Excel and Power Query**.

I analyzed **5,000 transaction records**, beginning with defining the business questions before profiling, cleaning, transforming, and validating the dataset in Power Query. I then used PivotTables and Excel charts to analyze sales trends, product performance, geographic performance, and delivery outcomes.

The final output is an **interactive Excel dashboard** supported by documented cleaning steps, validation rules, business findings, and recommendations.

## Dashboard

![E-Commerce Sales Dashboard](https://raw.githubusercontent.com/steve-analyst2/E-Commerce-Sales-Analysis/main/6-images/06-dashboard.jpeg)

The dashboard provides an interactive view of sales and customer performance, with slicers for **Year, Product Category, Country, and Delivery Status**.

### Key Performance Indicators

- **Total Sales:** KES 1,243,391.60
- **Valid Orders:** 4,960
- **Average Order Value:** KES 252.55
- **Average Customer Rating:** 3.44 / 5
- **Average Shipping Time:** 4.53 Days

## Key Insights

- **Electronics generated approximately 64.2% of total sales.**
- The **Top 5 products generated approximately 70.5% of total sales.**
- **Laptop Pro 14 and Smartphone X12** together generated approximately **55.8% of total sales.**
- **Uganda was the highest-performing country**, while sales remained relatively diversified geographically.
- **Returned and Cancelled orders represented approximately 41.6% of valid orders**, highlighting an area requiring further operational investigation.
- Incomplete late-2026 records demonstrated the importance of checking data completeness before interpreting performance trends.
